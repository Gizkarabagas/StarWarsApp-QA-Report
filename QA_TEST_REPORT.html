🚀 5 Langkah Rekomendasi Solusi Cepat (Bisa Kamu Sebutkan Pas Interview)
  1. 1
    Fix Blocker Crash (Butuh 2 Menit Saja)
    Tambahkan Platform di baris import 'react-native' pada LoginScreen/index.js dan GroupHomeScreen/index.js. Login dan notifikasi langsung berjalan normal!
  2. 2
    Normalisasi Input Email
    Gunakan email.trim().toLowerCase() saat registrasi dan login, serta tambahkan autoCapitalize="none" pada TextInput agar keyboard HP tidak otomatis memberi huruf kapital.
  3. 3
    Fix Pencarian SWAPI di Sisi Klien
    Unduh seluruh daftar orang/pesawat 1 kali saja dari swapi.info saat aplikasi dibuka, lalu lakukan pencarian lokal (filter array) di HP agar responsif dan tidak mengirim request sia-sia.
  4. 4
    Amankan Penyimpanan Kredensial
    Gunakan new MMKV({ encryptionKey }) dengan kunci dari Keychain/Keystore HP, dan jangan pernah menyimpan password plaintext di dalam database lokal.
  5. 5
    Dukung Layar Miring & Tablet
    Hapus Object.freeze(Metrics) statis di GlobalConfig.js, dan ganti dengan hook bawaan React Native useWindowDimensions() agar otomatis menyesuaikan saat layar diputar.

Blocker BUG-FUNC-09: Missing Platform import completely breaks Login
src/screens/LoginScreen/index.js:51
User Impact: 100% of login attempts fail with "You must allow location permission on this app to login" regardless of granted permissions.
Technical Cause: Platform.OS === 'android' is called without importing Platform from react-native, triggering an uncaught ReferenceError inside the location permission handler.
// Remedy: Add Platform to react-native imports in LoginScreen/index.js import { View, Text, TextInput, TouchableOpacity, PermissionsAndroid, Platform, ... } from 'react-native';
Critical BUG-FUNC-21: Missing Platform import crashes app on Group Invitation
src/screens/GroupHomeScreen/index.js:102
User Impact: When an invited user (e.g. Darth Vader) logs in and views their home tab, the app abruptly crashes / force-closes.
Technical Cause: sendPushNotification() evaluates Platform.OS === 'ios' without importing Platform, throwing an unhandled ReferenceError.
// Remedy: Add Platform import in GroupHomeScreen/index.js import { View, Text, FlatList, Image, TouchableOpacity, Platform } from 'react-native';
Critical BUG-SEC-01: Plaintext password storage and comparison in MMKV
src/utils/Storages.js:3 & apiServices.js:25
User Impact: Any malicious app or physical attacker accessing local app files can extract every user's plaintext password.
Technical Cause: new MMKV() is created without an encryption key; passwords are stored unhashed in LIST_USER and compared with ===.
// Remedy: Hash passwords server-side or via PBKDF2/bcrypt, and initialize MMKV with keychain-backed key: export const storage = new MMKV({ id: 'starwars-secure', encryptionKey: secureKeyFromKeychain });
High BUG-FUNC-13: SwapiScreen server-side ?search= query ignored by swapi.info
src/screens/SwapiScreen/index.js:26
User Impact: Searching for "vader" or "falcon" does not filter results; all 82 characters are displayed starting with Luke Skywalker.
Technical Cause: https://swapi.info/api/people/?search=vader does not implement server-side search and returns the entire unpaginated array.
// Remedy: Perform client-side debounced array filtering: const filtered = allSwapiData.filter(item => item.name.toLowerCase().includes(searchQuery.toLowerCase()));

High BUG-COMP-01: Frozen Dimensions.get('window') breaks Landscape & Tablets
src/utils/GlobalConfig.js:15-20
User Impact: Rotating device to landscape clips forms, freezes camera box proportions, and leaves TabBar unscaled.
Technical Cause: Dimensions are frozen at app boot via Object.freeze(Metrics). useWindowDimensions() is never used.
// Remedy: Use React Native's responsive hook in components: const { width, height } = useWindowDimensions();
